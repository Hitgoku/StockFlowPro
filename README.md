
# StockFlow Pro – Inventory & Supply Chain Management System

## Project Overview
StockFlow Pro is an inventory management application developed using Python, MySQL, SQL and Streamlit.

The application helps manage products, suppliers, stock levels, reorders, shipments and product inventory history.

## Technologies Used
- Python
- MySQL
- SQL
- Streamlit
- MySQL Connector for Python

## Main Features
- Product Management
- Supplier Management
- Product and Stock Information
- Place Reorders
- Receive Reorders
- Shipment Recording
- Product Inventory History

## Project Structure
- `app.py` – Main Streamlit application.
- `db_functions.py` – Database connection and SQL query functions.
- `requirements.txt` – Required Python packages.
- `database_backup.sql` – Database backup (to be added).

## Installation and Setup

### 1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure MySQL
Create the MySQL database and import the provided SQL backup.

Configure your database credentials before running the application.

### 4. Run the application
```bash
streamlit run app.py
```
